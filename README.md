\# RRIBuilder



RRIBuilder は、Web RRI 関連の C++ / MFC ベース GUI アプリケーションです。  

本リポジトリでは、既存のデスクトップアプリケーション資産の保守・改修・機能追加を行います。



\---



\# 開発環境



\## 推奨環境



\- Windows 10 / 11

\- Visual Studio 2019 または 2022

\- Git

\- GitHub



\## 使用技術



\- C++

\- MFC

\- Win32 API
